#+title: rugit – Project Tasks

* Tasks

** DONE Line-level staging
Stage/unstage individual lines within a hunk (visual selection or cursor-based). The UX model: expand a hunk, move cursor to a line, press =s= to stage just that line. Requires splitting hunks in the backend and applying partial patches.

** DONE Visual-mode multi-line staging (=V=)
Press =V= to enter visual mode, move with =j=/=k= to extend the selection, then =s= or =u= to stage/unstage all selected =+=/=-= lines. Multiple hunks per file are handled by building one patch per hunk from the cached diff. =Esc= exits visual mode.

** DONE Branch management popup (=b=)
Magit-style transient: =b b= checkout, =b c= create+checkout, =b d= delete, =b r= rename. Needs a branch list picker UI.

** TODO Interactive rebase UI (=r i=)
Show rebase todo list (pick/reword/edit/squash/fixup/drop per commit). Arrow keys to reorder, keybinds to change action. Drives =git rebase -i= via a custom sequence editor.

** DONE Instant fixup/squash (=c F= / =c S=)
Magit-style: pick a commit from a list, create a fixup or squash commit targeting it, optionally auto-rebase immediately.

** DONE Instant reword (=r w=)
Pick a commit, edit its message, and replay later commits onto it. Uses =git commit --fixup=reword:= plus the existing autosquash rebase. Refuses a dirty index, and drops the temporary =amend!= commit if the rebase fails.

** DONE Remove a commit (=r k=)
Magit-style: pick a commit and drop it from history, replaying later commits (=git rebase --onto <hash>^ <hash>=). Refuses the root commit and any uncommitted changes to tracked files (no autostash: a conflicting re-apply is reported by git as success), and aborts the rebase on conflict. jj backend uses =jj abandon=.

** TODO Diff viewer buffer (=d= on a commit or file)
Full-screen diff view, navigable by hunk. Invoked from log buffer (=d= on selected commit) or status buffer (=d= on a file). Syntax-highlighted diff lines.

** TODO Log buffer improvements
Current log buffer is minimal. Add: commit graph rendering (=--graph=), author/date columns, pressing =Enter= to open diff viewer.
Filtering (=/=, live narrows list by hash/author/message, =Esc= clears) is DONE — see below.

** DONE Stash popup (=z=)
=z z= stash, =z p= pop, =z a= apply, =z d= drop, =z l= list stashes. Stash list UI with navigate + apply/pop/drop actions.

** TODO Rebase/merge menus (=r=, =m=)
=r r= rebase onto branch, =r e= rebase --continue, =r a= abort. =m m= merge, =m a= abort.

** DONE Visual selection in commit editor (=v= / =V=)
=v= (charwise) or =V= (linewise) in Normal mode starts a selection; motions extend it; =y=/=d=/=x=/=c= yank/delete/change (Vim-inclusive), =Esc= or the same key cancels. =p=/=P= paste the yank buffer (linewise yanks, including =dd=, paste as whole lines below/above).

** DONE Extended vim bindings in commit editor
=o=/=O= open line below/above, =w=/=b=/=e= word motions, =G=/=gg= jump to end/start, =u=/=C-r= undo/redo, =yy=/=p=/=P= yank and paste line.

** TODO Colour themes (catppuccin, gruvbox, nord)
Theme enum in config.toml, palette lookup table, pass palette through render calls.

** TODO jj backend – full implementation
Implement all Backend trait methods using =jj= subprocess calls.

** TODO Packaging (Homebrew formula, AUR PKGBUILD, Nix flake)

** TODO Async push/pull with progress indicator
Push and pull currently run inline and block the UI (status_msg, =draw()=, then the backend call). Run them on a worker thread and report completion through the event loop, with a spinner in the footer, so the status buffer stays live (and auto-refresh keeps working) during a slow network operation. Needs a channel the loop polls alongside the watcher, and a guard against starting a second network op while one is running.

** TODO Command palette (=:= or =M-x=)
Fuzzy-searchable list of every action with its keybinding; Enter runs it. Doubles as discoverability and a home for rarely used commands. Reuses the =Action= enum and the log filter's matching.

** TODO Keymap config
User-remappable keys in =config.toml= (e.g. a =[keys]= table of key → action name), plus "magit" and "lazygit" presets. Needs =key_to_action= to consult a lookup table built from config instead of hard-coded matches, and the help popup / footer to render the active bindings.

* Done

** DONE Highlight files changed outside rugit
After a background refresh, files that appeared or whose kind/mtime/size changed get an amber row tint for ~1.5s, as do added/removed diff lines that changed inside expanded files (line-diffed old vs new with =similar=), so a shifting list doesn't look like a glitch. Changes rugit made itself don't flash: the baseline updates on every refresh.

** DONE Background auto-refresh (filesystem watcher)
=notify= watches the repo root; the event loop polls with a 150ms quiet window and re-reads status when something changed. Ignores gitignored paths and =.git= churn (only index/HEAD/refs count). Skipped while an editor, popup, visual selection or chord is active, and applied once that ends. Expanded diffs are re-fetched and the cursor stays on the same item. =g= still refreshes by hand.

** DONE Makefile for common commands
Targets for install, run, test and lint (clippy); =make= alone prints the help.

** DONE Cleanup pass (dead code, dedup, allocation cuts)
Remove dead code (=Config.editor=, unused push/pull output, clippy warnings);
=run_git=/=pipe_git= helpers in the git backend; one =diff= module for hunk/line
patch extraction; merge the three visual-selection handlers and the duplicated
status sections; shared popup menu/picker rendering; split =run_app=; stop
cloning diffs and status items per keypress/frame. Also: =#[serde(default)]= so a
partial =config.toml= no longer silently drops every setting.

** DONE Clippy tidy pass
Collapsed a redundant =if= into a match guard, =map_or= / =str::to_string= in place of
closures, inlined format args, nested or-patterns, and =writeln!= instead of
=push_str(&format!(..))= when building hunk patches.

** DONE Performance pass (idle redraws, windowed status render, batched staging, fewer git walks)
Windowed status rendering so per-frame work scales with the viewport rather than
the item count; redraw only after an event instead of 4x/second while idle;
batched =stage_files= so staging a section writes the index once; dropped
redundant =log()= re-walks from staging/discard paths; =stash_list= via the
=refs/stash= reflog instead of a =git= subprocess; capped the unpushed revwalk at
100 materialised commits (=unpushed_total= keeps the header count exact); cached
the log filter match list.
